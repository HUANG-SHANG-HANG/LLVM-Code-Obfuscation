# 基于 LLVM IR 的多策略代码混淆技术研究


本项目为毕业设计，主要研究并实现了一种**多策略代码混淆系统**。通过在 LLVM IR（中间表示）层面应用多种混淆策略，提升程序的抗逆向分析与抗篡改能力。


## 一、 项目描述与核心研究内容


本项目主要从**控制流混淆**与**数据流混淆**两个维度展开研究：


### 1. 针对控制流混淆
主要采用**不透明谓词**与**控制流重构**技术来隐藏真实执行路径：


*   **混合型不透明谓词的构造方法**：
    构造基于**混沌映射**和**并发线程**的混合型不透明谓词。
    *   **混沌子谓词**：基于二维帐篷映射实现，使用线程 ID 作为种子进行 N 次迭代，得到的值用于构建混沌子谓词表达式。
    *   **线程子谓词**：使用守护线程持续写入某特定值，构建恒真的线程子谓词。
    *   **高安全性组合**：使用 OR 逻辑连接混沌子谓词和线程子谓词。这种混合谓词使得攻击者必须**同时破解两个子系统**才能安全移除谓词，而且任一子系统失效都**不影响程序正确性**。
*   **不透明谓词的插入策略**：
    *   找到**循环**、**分支**的判断条件插入不透明谓词。
    *   将原有控制流拆分为**调度器**与**基本块**，在调度器中加入不透明谓词来决定跳转目标，以实现**隐藏现有分支**和**构造虚假分支**。


### 2. 针对数据流混淆
主要研究**数组混淆**，打乱内存中数据的存储规律：
*   **多维数组展平**：将多维数组全部展平为一维数组，得到初始线性索引 `i`。
*   **索引加密映射**：对得到的一维数组进行索引加密，生成加密索引 `i_enc`。
*   **数组动态拆分**：将一维数组进行拆分，对加密索引 `i_enc` 进行二次映射，动态确定数据**保存在哪一个子数组**以及在**该子数组中的偏移量**。


## 二、 多策略代码混淆系统与目录结构


结合上述控制流和数据流混淆技术，本项目实现了一个多策略协同的代码混淆系统。


### 项目目录结构


```text

│
├── toolChain/              # LLVM 工具链环境
│   ├── llvm-project/       # LLVM 15 源码
│   └── build-llvm15/       # 编译好的 LLVM 工具链产物（包含 clang/opt/llc）

├── passes/                 # LLVM Pass 插件（核心混淆模块）

│   │   └── build.sh                      # 编译为 .o 供后续链接
│   │
│   ├── control-flow-obfuscation-pass/    # Out-Of-Tree Pass A：控制流混淆
│   │   ├── src/ControlFlowObf.cpp
│   │   └── CMakeLists.txt                # 将控制流混淆 C++ 源码编译成动态链接库 .so
│   │
│   ├── array-obfuscation-pass/           # Out-Of-Tree Pass B：数组混淆
│   │   ├── src/ArrayObf.cpp
│   │   └── CMakeLists.txt                # 将数组混淆 C++ 源码编译成动态链接库 .so
│   │
│   ├── scripts/                          # 测试与自动化运行脚本
│   │   ├── common.sh                     # 公共路径与环境变量配置
│   │   ├── build_all.sh                  # 一键编译所有 Pass + runtime
│   │   ├── run_cf.sh    <test.c>         # 仅执行控制流混淆
│   │   ├── run_array.sh <test.c>         # 仅执行数组混淆
│   │   └── run_both.sh  <test.c>         # 执行多策略混淆（先 CF 后 Array）
│   │
│   └── README.md
│
├── sandbox/                # 环境沙盒验证
│   └── hello-pass/         # 最小 Pass 示例，用于验证外挂 Pass 模块和 LLVM 环境可用性
